# MCTGAuth Client

Клиентский мод NeoForge 1.21.1 для сервера MCTGAuth. Требуется Java 21, Minecraft 1.21.1 и NeoForge 21.1.244 (либо совместимая версия 1.21.x). Установите только `build/libs/mctgauth-client-0.6.5.jar` в `mods/` игрока.

Клиент хранит выданный Telegram пароль в `.minecraft/config/mctgauth-client.json` в открытом виде — это решение продукта. Защитите папку конфигурации и не передавайте её другим. Это единственное разрешённое место открытого пароля: он не отправляется backend, не попадает в диагностику и не передаётся по Minecraft-протоколу. Argon2id вычисляется вне render-потока, отправляется только nonce-связанный proof HMAC-SHA256.

## Настройки и аутентификация

Откройте **MCTGAuth** кнопкой титульного экрана или через **Mods → MCTGAuth Client → Config**. Доступны ввод, изменение и удаление пароля, **Show Password** и **Automatic Authentication**. Автоматическая авторизация означает «автоматически ответить после запроса сервера с MCTGAuth», а не запускать авторизацию при любом подключении. При отказе сохранённого пароля клиент попросит новый. Удаление локального значения не меняет пароль аккаунта в backend.

MCTGAuth Client можно оставить установленным для одиночной игры и серверов без MCTGAuth. Такие подключения остаются пассивными: не запускаются таймер авторизации, отправка payload, экран пароля, подмена причины отключения, reconnect или вычисление Argon2id. В частности, стороннему серверу не отправляется proof, производный от пароля, или другой материал авторизации. Авторизация включается только после корректного объявления `mctgauth:server_hello` текущим удалённым сервером.

Клиент и сервер согласуют протокол версии 2. После активации worker авторизации собирает только включённые сигналы устройства и передаёт типизированные SHA-256 digest: сильные сигналы включены, слабые GPU/MAC выключены по умолчанию. Исходные значения не передаются и не журналируются. Локальный серверный кэш поддерживает настроенную политику входа без backend и блокирует известные запрещённые устройства.

## Сборка и устранение проблем

```powershell
.\gradlew.bat :auth-neoforge-client:test
.\gradlew.bat :auth-neoforge-client:build
.\gradlew.bat :auth-neoforge-client:runClient
```
