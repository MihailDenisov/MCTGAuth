# MCTGAuth 0.6.3

[English version](RELEASE_NOTES_0.6.3.md)

## Backend-only выпуск для развёртывания

MCTGAuth 0.6.3 был выпущен как backend-only сборка ветки исходного кода 0.6.2. В неё входит завершённое исправление сохранения heartbeat: повторные принятые heartbeat обновляют существующую строку `server_status`, продвигают `last_heartbeat_at` и счётчики игроков, сохраняют время запуска того же экземпляра, заменяют метаданные нового экземпляра и очищают состояние остановки.

Успешный HTTP-ответ по-прежнему означает, что транзакция heartbeat зафиксирована. Устаревший heartbeat получает ответ conflict, а ошибка сохранения — ответ, отличный от успешного, с безопасным журналированием без секретов.

## Совместимость

- Схема базы остаётся `6`; миграции с 0.6.2 нет.
- Wire-протокол авторизации остаётся `1`.
- Клиентский и серверный Minecraft-моды версии 0.6.3 не требуются.
- Существующая конфигурация 0.6.2 остаётся действительной.

См. [руководство перехода с 0.6.2 на 0.6.3](MIGRATION_0.6.2_TO_0.6.3_RU.md).
