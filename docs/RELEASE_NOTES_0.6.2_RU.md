# MCTGAuth 0.6.2

[English version](RELEASE_NOTES_0.6.2.md)

## Исправления интерфейса Telegram

- Кнопка **Назад** в разделе **Информация о сервере** теперь использует явный стабильный callback `server_info:back` и всегда открывает обычное меню пользователя.
- Модератор, открывший «Информацию о сервере» из пользовательского меню, также возвращается в пользовательское меню; `/adm` остаётся отдельной авторизованной точкой входа в администрирование.
- Все действия раздела получили единообразные эмодзи: 📖 Как играть, 📦 Скачать сборку, 🗺 Веб-карта, 📡 Статус сервера и ⬅️ Назад.
- Необязательные кнопки сборки и карты по-прежнему скрыты, если для них не задан корректный включённый URL в существующей конфигурации.
- Русские и английские подписи используют одинаковые callback ID, не зависящие от языка.

## Включённое исправление телеметрии

- В этот выпуск входит завершённое исправление heartbeat выделенного сервера: периодическая задача переживает отдельные ошибки, сохраняется для управления жизненным циклом, работает в отдельном daemon-потоке, запускается после события готовности сервера и останавливается только при штатной остановке сервера.
- Диагностика жизненного цикла heartbeat сообщает безопасное состояние и тип исключения, не записывая bearer-токены или заголовки авторизации.
- Backend теперь правильно распознаёт тот же `serverInstanceId`, обновляет `last_heartbeat_at` и счётчики игроков при каждом применённом heartbeat, сохраняет `started_at` текущего instance, заменяет метаданные более нового instance и очищает `shutdown_at` при возобновлении работы.
- HTTP-ответ `200 accepted` отправляется только после commit транзакции heartbeat. Устаревший heartbeat получает `409`, а ошибка сохранения — `500` с безопасным типом серверной ошибки.

## Совместимость

- Схема базы данных остаётся версией `6`; новых миграций нет.
- Версия wire-протокола аутентификации остаётся `1`.
- Конфигурация backend, Minecraft-кэш аутентификации и клиент-серверная авторизация совместимы с 0.6.1.

См. [руководство перехода с 0.6.1 на 0.6.2](MIGRATION_0.6.1_TO_0.6.2_RU.md).
